## 🚀 Featured Work

### 🐦 Persian Social Media Analytics

An end-to-end computational pipeline for studying large-scale Persian social media discourse.

**Pipeline:**

`Data Collection → Preprocessing → NLP → Topic Modeling → Embeddings → Clustering → Network Analysis → Statistical Evaluation`

Methods and technologies include:

`Twikit` • `LDA` • `TF-IDF` • `Transformers` • `DBSCAN` • `Louvain Community Detection` • `Network Analysis`
